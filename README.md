# Linux Basics – Mini Project

## 📌 Project Overview

This project is a practical introduction to Linux fundamentals. It demonstrates basic Linux terminal operations, filesystem navigation, file management, and directory organization using Debian Linux.

## 🎯 Project Objectives

- Understand the Linux filesystem hierarchy.
- Practice navigating directories using the Linux terminal.
- Create, copy, move, rename, and remove files.
- Create and organize directories.
- Apply basic Linux commands in a practical project.

## 🛠️ Environment

- Operating System: Debian Linux
- Virtualization: VMware
- Shell: Bash
- Version Control: Git
- Remote Repository: GitHub

## 📚 Linux Commands Used

| Command | Description |
|---|---|
| pwd | Display current directory |
| cd | Navigate between directories |
| ls | List files and directories |
| touch | Create files |
| mkdir | Create directories |
| cp | Copy files |
| mv | Move or rename files |
| rm | Remove files |
| ls -R | Display directory contents recursively |
